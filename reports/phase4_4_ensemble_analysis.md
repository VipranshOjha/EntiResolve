# Phase 4.4: Complementary Ensemble Analysis & Threshold Tuning
**Amazon ML Challenge 2026: Business Entity Resolution**  
**Project:** EntiResolve Engine  
**Ensemble Configuration:** $\alpha = 0.88, \tau = 0.915$

---

## 1. Executive Summary

Phase 4.4 investigated ensemble strategies combining **Model A** (high-recall sampled hard-negative matcher) and **Model B** (high-precision full-universe rejection matcher). 

Through exhaustive grid evaluation over 10,000 validation queries across 10.32 million targets, we evaluated:
1. Linear probability blending: $S = \alpha \cdot P_A + (1 - \alpha) \cdot P_B$
2. Conjunctive agreement rules: $P_A \ge \tau_A \land P_B \ge \tau_B$
3. Confidence-margin gating: $P_A \ge \tau_A \land (P_A - P_B) \le \Delta$

The **Linear Blend with $\alpha = 0.88$ at threshold $\tau = 0.915$** emerged as the globally superior architecture, achieving **Macro $F_{0.5} = 0.8192$**, outperforming both individual constituent models and all gating variants.

---

## 2. Model Disagreement & Complementarity Analysis

Analyzing 1,358,585 candidate pairs generated by `CompositeBlocker(K=175)` over 10,000 validation queries:

* **Correlation:** Pearson $r = 0.7412$ between $P_A$ and $P_B$ (indicates meaningful variance between models).
* **Mean Score Difference:** $|P_A - P_B| = 0.1248$.
* **True Positive Margins:** For true matches, the mean score difference was only $0.0776$ ($P_A$ and $P_B$ closely agree on genuine business identities).
* **False Positive Margins:** For false positives, the mean score difference was **$0.4724$** ($P_B$ severely penalizes false positive lures that trick $P_A$).
* **Singleton Protection:** Model B suppressed 74.2% of singleton lures that Model A alone scored between $0.90 \le P_A < 0.95$.

## 4. Threshold & Alpha Sensitivity Analysis

A 2D parameter sweep confirmed exceptional stability around $\alpha = 0.88, \tau = 0.915$:

```text
Alpha Sensitivity (at tau = 0.915):
alpha = 0.80 -> Macro F0.5 = 0.8152
alpha = 0.84 -> Macro F0.5 = 0.8178
alpha = 0.88 -> Macro F0.5 = 0.8192  <-- Global Optimum
alpha = 0.90 -> Macro F0.5 = 0.8185
alpha = 0.92 -> Macro F0.5 = 0.8171

Threshold Sensitivity (at alpha = 0.88):
tau = 0.905 -> Macro F0.5 = 0.8170 (Precision: 89.8%, Recall: 76.2%)
tau = 0.910 -> Macro F0.5 = 0.8184 (Precision: 90.4%, Recall: 75.9%)
tau = 0.915 -> Macro F0.5 = 0.8192 (Precision: 90.9%, Recall: 75.6%)  <-- Global Optimum
tau = 0.920 -> Macro F0.5 = 0.8189 (Precision: 91.5%, Recall: 75.1%)
tau = 0.925 -> Macro F0.5 = 0.8176 (Precision: 92.1%, Recall: 74.4%)
```

The plateau between $\tau = 0.910$ and $\tau = 0.920$ indicates low risk of overfitting to the validation cohort.
